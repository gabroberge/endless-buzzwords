# Endless Buzzwords™

> **Cadence:** 5/week  
> **Authority:** Senior  
> **Original thoughts:** 0  
> **Content runway:** Somehow still 4 days

**Endless Buzzwords** is content operations for technical brands that have accepted the most important truth of modern thought leadership:

You do not need more ideas. You need the same idea on more platforms.

**Live demo:** https://gabroberge.github.io/endless-buzzwords/

---

## The platform

Endless Buzzwords helps technical brands maintain a continuous public presence without allowing originality to become a bottleneck.

Compose content. Increase seniority. Add buzzwords. Queue it. Schedule it. Repeat until authority has been established.

Included capabilities:

- **Pipeline** — keep the feed alive and monitor how long you have before silence
- **Compose** — turn topics into sufficiently authoritative content
- **Library** — preserve every reusable thought for future extraction
- **Coverage** — ensure no content pillar is allowed to rest
- **Channels** — distribute the same expertise across more surfaces
- **Brand** — configure how seriously the internet should take you

No AI APIs are involved. The buzzwords are artisanal.

## Getting started

```sh
bun install
bun dev
```

Production, insofar as any of this is production:

```sh
bun run build
bun run check
bun run preview
```

Built with Astro and TypeScript. The application is entirely client-side.
